# design-wisdom

AI agent skill: the tactics working designers use to find and fix UX problems in web apps. Audit moves (blur it, break it, compare screen 1 with screen 80, five-second cold read), state and flow patterns, conversion, premium feel, psychology and brand.

## Install

```sh
npx skills add saurav-codes/design-wisdom -g
```

## What it covers

- A core playbook of review moves an agent can run on a rendered product.
- Eight references with about 500 merged entries, each with what to look for, the fix, and source videos.
- Pairs with [frontend-design](https://github.com/saurav-codes/frontend-design): that skill sets taste rules, this one finds what is wrong. On conflicts, frontend-design wins.

Distilled from about 800 transcribed videos by Tim Gabe, DesignSpo, uxpeak, Hatch Conference, Satori Graphics, Will Paterson, Amir Moradi, Shantanu Kumar, Self-Made Web Designer and GraphiqVibe.
